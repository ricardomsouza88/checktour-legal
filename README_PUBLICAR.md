# Publicação do site legal CheckTour

Antes de publicar:

1. Substitua em todos os arquivos:
   suporte.checktour@gmail.com
   pelo e-mail oficial do CheckTour.

2. Publique a pasta `legal_site` em uma URL HTTPS pública.

Opções gratuitas:
- GitHub Pages
- Netlify
- Cloudflare Pages
- Firebase Hosting (pode depender do plano/configuração do projeto)

URLs que deverão ser informadas na Google Play:
- /privacidade.html
- /excluir-conta.html

Também é recomendável disponibilizar:
- /termos.html

Não publique com o placeholder de e-mail.
