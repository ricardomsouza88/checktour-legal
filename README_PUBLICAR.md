# Publicação do site legal CheckTour

Antes de publicar:

1. O e-mail oficial já está configurado como `suporte.checktour@gmail.com`.

2. Publique a pasta `legal_site` em uma URL HTTPS pública.

Opções gratuitas:
- GitHub Pages
- Netlify
- Cloudflare Pages
- Firebase Hosting (pode depender do plano/configuração do projeto)

URLs que deverão ser informadas na Google Play:
- /privacidade.html
- /excluir-conta.html

Também é recomendável disponibilizar:
- /termos.html

O e-mail oficial já está configurado.
